設計思想Philosophy

データは他人のサーバーではなくあなたのディスクに On your disk, not the cloud.

Atelieがあなたのデータを外部へ送信することは絶対にありません。同期はアプリではなく、あなたが使い慣れた git に任せましょう。 Atelie never sends your notes to someone else's server. Files are yours. Sync is your git's responsibility — not the app's.

01

データはプレーンなマークダウンMarkdown is the source of truth

データの実体はローカルの .md ファイル。独自のデータベースにあなたをロックインしません。 Every note lives as a plain .md file under your workspace. Uninstall Atelie tomorrow — your notes are still right there.

02

外界からの完全な隔離Offline-only, single-user

アカウント登録も、裏側での通信（テレメトリ）も一切ありません。例外はアップデートチェックだけで、これも opt-out 可能。 No external APIs, no auth, no telemetry. The one exception is the update check on launch — and you can opt out.

03

同期は git で自由にコントロールSync is your responsibility

謎のバックグラウンド同期はしません。git init すれば、好きなリモートリポジトリで安全にデータを管理できます。 The app doesn't call git. Run git init in your workspace once, then sync to whichever remote you trust.

04

外部エディタと共存Lives next to your editor

VS Code でも Neovim でも、好きなエディタで開いて編集できます。ファイル監視機能が自動で取り込みます。 Open the same files in VS Code or Neovim. The file watcher picks up your edits automatically.

05

Tauri 製、軽快なネイティブBuilt with Tauri, light and native

Rust と WebView の組み合わせで、Electron のような重さはありません。起動も操作も、Mac らしく素早く。 Rust core, system WebView, no Electron bulk. Launches fast, stays responsive — the way a Mac app should feel.

主要機能Features

機能は最小限・動作は最速 Small, quiet, and gets out of the way.

なんでもできる重いSaaSは、もう要りません。個人の開発者が毎日のタスクとノートを管理するために必要な機能だけを、極限まで磨き上げました。 No feature creep. Just what a freelance developer actually needs to track tasks and notes day to day — built carefully.

マークダウンエディタMarkdown editor

Tiptap 3 + frontmatter プロパティパネル。本文も YAML も同じファイルで一貫管理。 Tiptap-based editor with a YAML frontmatter property panel. One file, body and metadata together.

Tiptap 3 · GFM

Wikilink + バックリンクWikilinks + backlinks

[[note-id]] で双方向リンク。id が安定参照なので、ファイル名を変えてもリンクは切れません。 [[note-id]] creates a two-way link. Stable IDs mean renaming the file never breaks anything.

[[t-001]]

3 つのビュー、データは一つThree views, one source

Kanban でドラッグ、Table でソート、Calendar で期限俯瞰。ドロップすると frontmatter に書き戻します。 Drag in Kanban, sort in Table, scan deadlines in Calendar. Drops write back to frontmatter.

Kanban · Table · Calendar

全文検索（日本語対応）Full-text search (Japanese)

SQLite FTS5 trigram tokenizer で日本語もスムーズに検索。形態素解析の罠なし。 SQLite FTS5 with a trigram tokenizer — Japanese works smoothly, no morphological analyzer pitfalls.

FTS5 · trigram

プロジェクト別ステータスPer-project statuses

デフォルトは todo / doing / review / blocked / done。プロジェクトごとに .atelie/config.yml でカスタマイズ。 Defaults to todo / doing / review / blocked / done. Customize per project via .atelie/config.yml.

VS Code や Neovim で .md を直接編集しても、Atelie がファイル監視で即座に反映します。 Edit the .md in VS Code or Neovim — Atelie's file watcher picks it up instantly.
